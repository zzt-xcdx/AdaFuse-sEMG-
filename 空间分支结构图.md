## 3. 数据维度变化流程图

```
输入数据: (32, 12, 400, 1)
    │
    ▼
维度重排: (32, 1, 12, 400)  ← permute(0,3,1,2)
    │
    ▼
第1层卷积: (32, 16, 12, 400)  ← Conv2d(1→16) + BN + PReLU
    │
    ▼
第2层卷积: (32, 32, 12, 400)  ← Conv2d(16→32) + BN + PReLU
    │
    ▼
第1次池化: (32, 32, 6, 200)  ← MaxPool2d(2×2)
    │
    ▼
第3层卷积: (32, 64, 6, 200)  ← Conv2d(32→64) + BN + PReLU
    │
    ▼
第2次池化: (32, 64, 3, 100)   ← MaxPool2d(2×2)
    │
    ▼
自适应池化: (32, 64, 1, 64)  ← AdaptiveAvgPool2d
    │
    ▼
特征聚合: (32, 64)           ← view + mean
    │
    ▼
投影层: (32, 64)             ← Linear(64, 64)
    │
    ▼
最终输出: (32, 64)
```

## 5. 关键组件功能说明

### 5.1 批归一化 (BatchNorm2d)
```
作用: 稳定训练过程
输入: 任意形状的特征图
输出: 归一化后的特征图
效果: 加速收敛，提高训练稳定性
```

### 5.2 PReLU激活函数
```
作用: 增加非线性，提高模型表达能力
公式: f(x) = max(0, x) + α * min(0, x)
特点: 可学习的参数α，比ReLU更灵活
```

### 5.3 最大池化 (MaxPool2d)
```
作用: 减少数据量，保留重要特征
输入: (B, C, H, W)
输出: (B, C, H/2, W/2)
效果: 降低计算复杂度，提取主要特征
```

### 5.4 Dropout
```
作用: 防止过拟合
方法: 随机丢弃部分神经元
效果: 提高模型泛化能力
```

### 5.5 自适应池化 (AdaptiveAvgPool2d)
```
作用: 将特征图压缩到固定大小
输入: (B, 64, H, W)
输出: (B, 64, 1, 64)
特点: 无论输入大小如何，输出都是固定尺寸
```
